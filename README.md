# casestudy

Claude Code skill (`case-study-writer`) for framing, writing, self-reviewing and iterating Suraj's portfolio case studies.

- `SKILL.md`: rules, story loop, page structure, voice, review rubric, learnings log
- `references/exemplars.md`: patterns from studied case studies

Updated after every case study round.

## Layout

- `references/layout-hybrid.md`: sticky chapter rail + left-aligned column + sparing right margin, 7-9 chapters, headline rules, Figma workflow
- `references/motion-system.md`: Motion Load Score, thresholds, keep/adapt/skip for James Chugh's interactions
- `references/voice-and-story.md`: voice cleanup, story hand-offs, Wispr Flow interview mode
- `demo/layout-demo.html`: layout wireframe with a live motion meter (open in a browser)
- `scripts/motion-audit.mjs`: `node scripts/motion-audit.mjs <dir> --mode case --chapters 8`

Start any session with: "Use the case-study-writer skill and read SKILL.md section 9."
